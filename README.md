# Java_projects
Hybrid Cryptography System (Matrix & Substitution Cipher)The Hybrid Cryptography System is a Java-based command-line application designed to securely encrypt and decrypt text messages. It utilizes a multi-layered security approach by combining a dynamic Substitution Cipher (with positional shifting) and a Matrix-based Cipher (Hill Cipher variant) to ensure robust data protection.Key Features:1. Advanced Substitution LayerThis panel/module handles the initial level of encryption. Instead of a simple shift, it applies a mathematical formula incorporating a user-defined key, the character's position index, and a polynomial factor:$$\text{Encrypted} = (\text{Original} \times \text{Key} + \text{Position}^2 + \text{Key}^3) \pmod{26}$$This ensures that the same letter appearing at different places in the text encrypts to entirely different characters, breaking simple frequency analysis.2. Matrix Multiplication Cipher (Hill Cipher Variant)After substitution, the text is converted into its respective ASCII/numerical matrix ($Matrix\ A$). The system then requests an $n \times n$ Encoding Matrix ($Matrix\ B$) from the user to perform matrix multiplication:$$\text{Matrix } C = A \times B$$The output results in a highly secure numerical encrypted stream, separated visually for transmission.3. Automated Inverse Matrix DecryptionThe decryption module features a built-in Gaussian-elimination style inverse matrix calculator. It dynamically checks if the user's provided encoding matrix is invertible. If valid, it computes $Matrix\ B^{-1}$ automatically to reverse the matrix cipher layer:$$\text{Matrix } D = C \times B^{-1}$$This eliminates the need for the user to manually calculate or provide a decryption key matrix.4. Input Case & Padding RestorationThe system smartly handles standard input hurdles:Coprime Key Validation: It uses a Greatest Common Divisor (GCD) check to ensure the substitution key is coprime with 26 ($\gcd(\text{key}, 26) = 1$), preventing mathematical decryption failures.Auto-Padding: Automatically appends spaces if the text length doesn't perfectly fit the matrix dimensions.Case Sensitivity Retention: After full decryption, it retains and restores the exact upper and lower-case format of the user's original message.
